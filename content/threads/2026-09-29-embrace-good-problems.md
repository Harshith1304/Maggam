Problems are inevitable of which that I'm very sure. because everything that we do has even a few/minor problems attached to it and it always comes with a problem that we must deal with it. so when problems are impossible to not sprout then try going in path that has problem that are comfortable dealing with. Suppose you want to achieve a goal that comes with many sacrifices and problems, instead of chickening out and running away of problems make sure to face them head on head as diverting from your destined path can too comes with any inevitable problem which god knows. You cant run away from problems, you just switch or get introduced to encounter new problem. so when there is no escaping from problem then why not deal with problem that are not regrettable facing it for sake of sticking to the path to your goals. so it is very foolish to run and escape from problem instead of man up and facing it.
